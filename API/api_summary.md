# API Summary

## REST API
A REST API allows applications to communicate over HTTP using methods such as GET, POST, PUT and DELETE. It commonly exchanges data in JSON format.

## HTTP Status Codes
- 200 OK: The request was successful.
- 404 Not Found: The requested resource could not be found.

## jq Filters
jq is a command-line tool used to parse and filter JSON data. The filter `.name` extracts a field, while `length` returns the number of elements in an array.
